Scope

対応範囲外

現在は、静的Webサイト・配信オーバーレイ制作を中心に対応しています。トラブル防止のため、以下の内容は現在対応していません。

現在対応していない内容
  • ログイン機能・会員登録機能
  • 決済機能・ECサイト
  • 大規模なWebアプリ
  • サーバー構築が必要なシステム
  • 既存コードの大幅な改修
  • 複雑なデータベース連携
  • 高度なセキュリティ対応が必要な案件

GitHub Pagesで公開できる範囲の小規模サイトや、OBS / Streamlabsで使えるHTMLオーバーレイを中心に対応します。アラート用画面は今後対応予定です。対応できるか分からない場合も、まずは相談内容を確認してから判断します。

FAQ

よくある質問

コードが分からなくても依頼できますか？
はい、大丈夫です。使用目的や雰囲気を聞きながら、こちらで形にします。
OBSやStreamlabsで使えますか？
はい。HTML形式のブラウザソースとして使える形を想定しています。
修正はできますか？
はい。基本的に修正2回まで無料です。3回目以降や大幅な変更は追加料金、または別途見積もりになります。
商用利用できますか？
制作内容ごとに相談して決めます。BOOTH販売用、配信活動用、告知用など、用途を確認したうえで対応します。
Webサイト制作も依頼できますか？
はい。GitHub Pagesで公開できる小規模な静的サイトを中心に対応可能です。ログイン機能や決済機能が必要なサイトは対応していません。
依頼内容がはっきりしていなくても相談できますか？
はい。「こういうものは作れますか？」という相談だけでも大丈夫です。
