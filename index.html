画像生成作品

オリジナルの和装メイドを題材にしたスマホ壁紙セット。 GPT、ComfyUI、Codexを組み合わせ、テーマ設計・生成・選定・壁紙向け調整・権利チェックまで行いました。 既存IP名やエタリタ関連画像は使用していません。

  • 9:16スマホ壁紙向けの縦長構図
  • ロック画面・ホーム画面向けの明るさ調整
  • 色味違い・雰囲気違いのバリエーション制作
  • 権利チェックメモを作成し、公開リスクを確認
  • 販売・SNS投稿を見据えたプレビュー整理
制作期間 / 2026年5月
配信素材 OBS対応 6テーマ

配信オーバーレイ

OBS / Streamlabs 対応のブラウザソース用HTMLオーバーレイ。 opening・ending・BRB・live・camera・alertの6コンポーネントをテーマ切り替え式で制作。 自身の配信で実際に運用中。

  • 6コンポーネント（opening / ending / BRB / live / camera / alert）
  • 6テーマ（cyber neon / gothic dark / mono simple / natural spring / pastel pop / 和風dark）
  • 1920×1080 フルHD対応
  • CSS変数によるテーマ切り替えシステム
  • 自身の配信で実運用・継続改善中
